# Bubble Sort em C

Projeto desenvolvido para a disciplina de Algoritmos e Pensamento Computacional.

## Objetivo

Aplicar o algoritmo Bubble Sort para ordenar os preços de 10 produtos de supermercado.

## Funcionalidades

- Exibe os preços originais
- Ordena os preços em ordem crescente
- Ordena os preços em ordem decrescente
- Utiliza vetores e estruturas de repetição em C

## Tecnologias

- Linguagem C
- GCC
- Visual Studio Code
